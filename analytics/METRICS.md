# 数据粒度与指标字典

范围：单机构、单一 `pVersionId`、2026-11-09 周。时间以北京时间显示。`dataset-manifest.json` 保存当前提取时间、类型、数量、摘要和对账指标。所有 UUID 保持文本，日期与数值明确转换类型。

| 表 | 一行代表什么 | 当前行数与键 |
|---|---|---|
| FactDemand | 所选版本对应周的一条选课需求，含未安排标志 | 668；版本 + request_id |
| FactSession | 所选版本的一次正式课次 | 68；session_id |
| FactRoomSlot | 一间教室、一天、一个教学时段的开放能力 | 400；版本 + room_id + day + slot_code |
| FactConfirmation | 一个课次对应一名必要确认人的事项 | 736；session_id + user_id |
| DimStudent | 一名模拟学生 | 220；student_id |
| DimTeacher | 一名模拟教师，包括未排课者 | 16；teacher_id |
| DimRoom | 一间教室，保留全名与显示简称 | 10；room_id |
| DimCourse | 一门课程定义 | 13；course_id |
| DimDay | 版本周内一个工作日 | 5；day |
| DimSlot | 一个统一教学时段 | 8；slot_code |
| DimVersion | 一个课表版本及其状态、时间、质量摘要 | 1；version_id |
| MapCourseGroup | 一个课程分类的中文映射 | 4；course_group；在 Power Query 合并到 DimCourse |
| CheckList | 一个质量检查标签 | 5；与事实表不连线，用 SWITCH 度量展示 |

DimVersion 连接四个事实集；DimCourse、DimTeacher、DimRoom 连接含相应键的事实集；DimDay、DimSlot 连接相应日期和时段；DimStudent 只连接 FactDemand。FactDemand 的日期键为 scheduled_day，其余为 day。教师维度筛选确认表时，含该教师课次内师生双方的事项，不等于只筛选教师本人的确认。

| 指标 | 分子 / 分母或算法 | 当前值 | 解释限制 |
|---|---|---|---|
| 已审核需求 | APPROVED 的唯一 request_id | 668 | 待审核单独管理，不纳入本指标 |
| 需求满足率 | 已安排已审核需求 / 已审核需求 | 668/668 = 100% | 人次与独立学生数不同 |
| 独立学生数 | FactDemand 的唯一 student_id | 220 | 不用 SUM(student_count) 表示独立人数 |
| 安排人次 | 各课次 student_count 求和 | 668 | 同一学生选多课会出现多个人次 |
| 首选命中率 | 命中最小 rank 的已安排需求 / 已安排需求 | 206/668 = 30.84% | 用 EXISTS 避免偏好一对多连接放大 |
| 任一偏好命中率 | 命中任一偏好需求 / 已安排需求 | 336/668 = 50.30% | 包含首选；不能与首选人数相加 |
| 偏好结构 | 首选、其他意向、非意向互斥分组 | 206、130、332 | 三组共 668 |
| 时段覆盖率 | 有至少一班的日×时段 / 工作日×教学时段 | 40/40 = 100% | 机构覆盖；不是教室或教师利用率 |
| 教室时间占用率 | 已排教学分钟 / 教室开放教学分钟 | 3010/17500 = 17.20% | 不包含午休、课间；S8 为35分钟 |
| 教室座位利用率 | 安排人次 / 各课次教室容量之和 | 668/1572 = 42.49% | 按一次课的座位机会计算，不是学生/全校座位 |
| 有效班额填充率 | 安排人次 / min(课程容量,教室容量)之和 | 668/1360 = 49.12% | 与物理教室座位口径不同 |
| 平均班级人数 | 安排人次 / 课次数 | 668/68 = 9.82 | QA 与常规课一起计算 |
| 教师授课小时 | 每位教师课次时长合计 / 60 | 全机构50.17小时 | S8计一节，但只累计35分钟 |
| 教师日未授课时段 | 8 - 当天课次数 | 最少5节 | 不将课间、午休计入；移除课程、教室筛选后计算 |
| 确认完成率 | 指纹匹配的 ACCEPTED 事项 / 必要确认事项 | 736/736 = 100% | 668学生事项 + 68教师事项，全部为模拟账号确认 |
| 模拟发布至生效用时 | DimVersion 的 activated_at 减 published_at，转换为秒 | 91.69 秒 | 单周测试账号批量确认，用完整时间戳计算 |
| 首选提升百分点 | (最终首选数 - 基线首选数) / 全周审核需求 × 100 | 14.97个百分点 | 只用于同批需求的全周比较，不用于课程或年级切片后的基线比较 |

日期筛选按已排日期作用于需求；未排需求没有 scheduled_day，不能用切日后的值代替全周未满足数量。总览保持全周口径。质量检查中的硬冲突来自课表保存的独立校验报告；本次另在真实数据库复核，不能把它理解为持续进行生产安全审计。

主键无重复、必需键无缺失、关系完整性、每文件摘要、四事实集版本一致性及九项原始 SQL 对账均已检查。发布和生效是安排状态；真实出勤、反馈效果、营收与成本没有在此数据集中测量。
