# 公开副本验收

本轮在本地测试环境使用合成数据。以下结果来自 Windows、Python 3.12.14、Node.js 26.13.0、Docker Linux 容器和 Power BI Desktop。

| 验收项 | 本轮结果 |
|---|---|
| 从空环境准备依赖和构建 | 项目虚拟环境按锁文件安装，`pip check` 通过。管理端和师生端的 TypeScript、Vite 构建通过。构建检查确认师生端资源仅包含师生入口所需页面。 |
| 代码质量 | ESLint、Ruff 检查与格式检查通过。mypy 通过 43 个源文件，两条模块依赖契约通过。 |
| 独立首次启动 | 使用独立的 Compose 项目、镜像、数据库、Redis 和数据卷。迁移到 `0004`，初始化 220 名学生、16 名教师、10 间教室。两个回环入口就绪，管理员、教师和学生均经各自入口登录成功。 |
| 后端回归 | 回归 141 项通过，外加独立求解用例 1 项通过，合计 142 项。真实 PostgreSQL 用例覆盖选课、教师审核、求解、独立校验、发布、必要确认和整周生效。 |
| 220 人独立求解 | CP-SAT 返回 `FEASIBLE`。求解器记录 60.90 秒，得到 53 个课次、668/668 条已安排需求、40/40 个时段，独立校验硬冲突为 0。 |
| 历史数据库对账 | 在只读事务执行两版对比，最终版的九项 SQL 对账全部通过。11 份业务快照的行数、字段和 SHA-256 均与清单相符。 |
| PDF 和 PBIX | 两份交付文件与定稿的 SHA-256 一致。五页 PDF 的核心指标与分析快照一致。将 PBIX 验证副本移到独立目录，通过不可达的本机 PostgreSQL 端口验证内嵌快照刷新，并用「主课」筛选复核 263 条需求、60 条首选命中。 |
| 公开范围 | 公开清单共 193 个文件。逐项核对文档链接，扫描公开文本、前端构建与 PBIX 可读元数据，人工查看三端合成数据截图。 |

首次回归中，沙箱阻止 Windows 测试进程创建目录联接。获准在公开副本的私有测试目录创建联接后，同一测试随全套回归通过。锁定环境中的 Starlette 测试客户端仍发出一项弃用提示。

独立求解用例每次生成自己的候选。作品集固定展示 2026-11-09 业务周的历史生效版本，该版本共有 68 个课次、40 个覆盖时段和 736 项模拟确认。模拟发布至生效用时 91.69 秒。 [五页报告](portfolio/EduFlow-Case-Study.pdf) · [两版对比 SQL](../analytics/checks/CompareVersions.sql) · [两版汇总 CSV](../analytics/data/ScheduleComparison.csv) · [对账 SQL](../analytics/checks/Reconcile.sql)
